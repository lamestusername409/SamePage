# Same Page

A book club for two. Shared progress on one spine, spoiler-locked notes in the margin, and a deck of provocative questions.

Built as a plain web app (no build step). Hosted on GitHub Pages, data in Firebase (Auth + Firestore).

- `config.js` — who the two readers are, and the question deck
- `firestore.rules` — paste into Firebase console → Firestore → Rules
